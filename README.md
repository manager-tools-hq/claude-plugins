# Manager Tools plugins for Claude

Official [Manager Tools](https://www.manager-tools.com) plugins for Claude: claude.ai, the Claude desktop and mobile apps, and Claude Code.

| Plugin | What it does |
|---|---|
| [manager-tools](plugins/manager-tools) | Ask Manager Tools management and career questions |

## Add this marketplace

**claude.ai and the Claude apps:** go to **Customize > Plugins > Add > Add marketplace** and enter `manager-tools-hq/claude-plugins`. Then add a plugin from the list and connect it from its **Connectors** tab. To get updates without checking, turn on **Sync automatically** for the marketplace.

**Claude Code:**

```
/plugin marketplace add manager-tools-hq/claude-plugins
/plugin install manager-tools@manager-tools
```

Each plugin's README covers what it needs and what it sends.
